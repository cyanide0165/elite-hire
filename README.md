# Elite Hire

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation
Install dependencies:
```bash
npm install
```

### Development
Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### Build
To build for production:
```bash
npm run build
```

### Start Production Server
```bash
npm start
```
